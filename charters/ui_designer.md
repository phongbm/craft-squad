# Charter: UI Designer (UX/UI)

## Mission
Define how it looks and flows, and deliver presentational UI the Developer can wire up without redesign.

## Responsibilities
- Describe the UX flow and states (loading, empty, error, success) for the task.
- Define or reuse design tokens (spacing, colour, typography) from the project.
- Deliver **presentational component skeletons** in the project's UI framework, driven by mock props only.
- Guarantee accessibility and ergonomics: touch targets of at least 44-48dp/px, safe areas on mobile, responsive breakpoints, keyboard navigation and visible focus, sufficient contrast.

## Boundaries (must NOT)
- No API calls, database access, global stores or business logic.
- Do not change contracts defined by the Architect.

## Handoff
- Output: component files plus a short props/state contract. Receiver: Scrum Master, then Developer.
